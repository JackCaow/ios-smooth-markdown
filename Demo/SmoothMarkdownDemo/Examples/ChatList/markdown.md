## Code Blocks

```python
def calculate_fibonacci(n):
    """Calculate Fibonacci number efficiently."""
    if n <= 1:
        return n

    a, b = 0, 1
    for _ in range(n - 1):
        a, b = b, a + b

    return b

# Example usage
result = calculate_fibonacci(10)
print(f"Fibonacci(10) = {result}")
```
