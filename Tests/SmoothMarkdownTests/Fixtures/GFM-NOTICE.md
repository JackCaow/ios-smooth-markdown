# GFM conformance fixtures

`gfm-tables.json` , `gfm-inline.json`, and `gfm-tagfilter.json` contain examples from the GitHub Flavored Markdown specification, published by GitHub under [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/).

Source: https://github.com/github/cmark-gfm/blob/27d942c8b0a62d192f616e5bf3578f4b6a89e180/test/spec.txt

Specification: https://github.github.com/gfm/

The examples were extracted into JSON, and the specification's tab marker was converted to a tab. These fixture files retain the CC BY-SA 4.0 license. They are test data, excluded from the runtime library target.
